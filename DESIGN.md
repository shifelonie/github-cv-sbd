# Design system

## Direction

The portfolio is a creator-hardware desk: a tactile, workbench-like interface that frames Fadhil's skills as tools he uses to make useful digital products. It intentionally avoids the usual soft gradient hero and generic project-card grid.

## Palette

- Gunmetal background: `#171817`
- Raised panel: `#252725`
- Bone text/keycap: `#ece9dc`
- Putty surface: `#d8d6c7`
- Safety orange action: `#ff6a2a`
- Amber status: `#ffbf57`
- Green availability: `#a8d66d`

## Typography

Space Grotesk carries display and interface copy. DM Mono is reserved for labels, metadata, status text, and utility controls. Headings use tight tracking and a compact line-height.

## Composition

The page uses a sparse instrument layout: large typographic nameplate, an amber status console, a horizontal capability ticker, a timeline for evidence, a keycap grid for skills, and a contact console. Components use crisp borders, restrained shadows, and one authored tactile motion system.

## Interaction

Skill keys can be filtered by build/design category. The contact console includes a mail action and a copy-email action. All controls retain visible keyboard focus and support reduced motion.

## Responsive rules

Desktop uses split compositions and a wide key grid. Tablet collapses to a single-column hero and stacks education content. Mobile keeps the key units intact, reflows the timeline, and turns footer metadata into a vertical list.
